## 1. Overall Assessment

ChemEx (`v2026.09.2`, ~69,000 LOC across `src/chemex/`, Python `>=3.13`) is a capable, domain-rich scientific package whose **core NMR physics and equilibrium thermodynamics layers** show strong domain craftsmanship, but whose **recent native parameterization, optimization, and uncertainty layers** suffer from severe architectural over-engineering alongside subtle numerical, physical, and statistical defects.

### Key Strengths
1. **Clean Cartesian Liouvillian & Pulse-Sequence Architecture**: The separation between declarative operator bases in [basis.py](../../src/chemex/nmr/basis.py), Liouvillian assembly in [engine.py](../../src/chemex/nmr/_engine/engine.py), cached pulse propagators in [library.py](../../src/chemex/nmr/_pulses/library.py), and self-contained experiment plugins under `src/chemex/experiments/catalog/` makes most CPMG and CEST pulse sequences concise, readable, and faithful to experimental spin physics.
2. **Careful Equilibrium & Thermodynamic Math in Newer Kinetic Helpers**: The log-space root-finding and implicit-differentiation routines in [_binding.py](../../src/chemex/models/kinetic/_binding.py), [_oligomerization.py](../../src/chemex/models/kinetic/_oligomerization.py), and [_eyring.py](../../src/chemex/models/kinetic/_eyring.py) avoid classical catastrophic cancellation (`sqrt(b^2 - 4ac) - b`) across extreme $K_d$ and temperature regimes.
3. **Variable Projection (VarPro) of Profile Scale Factors**: Analytically profiling out the per-profile linear intensity scale in [native.py](../../src/chemex/evaluation/native.py#L301-L318) and accounting for `profiled_normalization_count` in reduced $\chi^2$, AIC, and BIC in [helper.py](../../src/chemex/optimize/helper.py#L54-L90) eliminates one nuisance variable per profile while preserving exact nonlinear least-squares optima.
4. **Tooling & Reproducibility Hygiene**: Both `ruff check .` and `ty check` pass cleanly with zero diagnostics; input TOMLs and execution metadata are archived into `run_info/` ([run_info.py](../../src/chemex/run_info.py)); and runtime state is encapsulated in `AnalysisSession` ([session.py](../../src/chemex/runtime/session.py)).

### Structural Weaknesses
1. **Extreme Disproportion Between Scientific Logic and "Proof Theater"**: Over **40% of the entire codebase (~28,200 LOC)** sits in a single-process cryptographic/witness verification layer across [uncertainty.py](../../src/chemex/optimize/uncertainty.py) (7,945 LOC), [native_mcmc.py](../../src/chemex/optimize/native_mcmc.py) (5,068 LOC), [direct_trf.py](../../src/chemex/optimize/direct_trf.py) (4,452 LOC), [native_resampling.py](../../src/chemex/optimize/native_resampling.py) (3,757 LOC), [native.py](../../src/chemex/evaluation/native.py) (2,157 LOC), [parameterization.py](../../src/chemex/parameters/parameterization.py) (1,943 LOC), [feasible_coordinates.py](../../src/chemex/parameters/feasible_coordinates.py) (1,849 LOC), and [grouped_direct_trf.py](../../src/chemex/optimize/grouped_direct_trf.py) (1,819 LOC). These modules wrap straightforward numerical operations in SHA-256 JSON Merkle digests, `WeakKeyDictionary` witness tokens, runtime `inspect.getsource()` disk hashing, and `__post_init__` hooks that re-run RNG sequences and matrix multiplications to verify data just computed three lines earlier in the same Python process—including **~1,635 LOC of dead, unreachable summary stacks**.
2. **Real Scientific & Numerical Bugs Behind Rigid Contracts**: While thousands of lines guard against hypothetical in-memory tampering, genuine physical and numerical failure modes—anti-phase $^{13}\text{C}$ relaxation signs, $^{15}\text{N}\text{–}{}^1\text{H}$ heteronuclear NOE equilibrium signs, real-Liouvillian conjugate ghost eigenvalues in chemical-shift experiments, Jordan-block propagator collapse, IEEE-754 ULP simplex boundary crashes, and unburned MCMC autocorrelation times—slip through unchecked.
3. **Missing Sparsity, Vectorization, and True Parallelism**: Global fits evaluate dense finite-difference Jacobians without `jac_sparsity`; CEST profiles loop over 50–100 RF offsets in Python instead of batching tensors; deterministic grid/grouped fits hardcode `workers = 1`; and resampling uses `ThreadPoolExecutor` while setting `OMP_NUM_THREADS` *after* NumPy/SciPy import (where OpenBLAS/Accelerate ignore environment changes).

### Tier 1 — Scientific & Numerical Correctness Defects

#### 1.1 [Confirmed Defect] Chemical-Shift Experiments Select Conjugate "Ghost" Eigenvalues and Pool Coherence Subspaces, Producing Silent `0.0` ppb or Inverted Shifts
- **Locations**: [analysis.py](../../src/chemex/nmr/_engine/analysis.py#L19-L25), [shift_15n_sqmq.py](../../src/chemex/experiments/catalog/shift_15n_sqmq.py#L37-L86), [shift_15n_sq.py](../../src/chemex/experiments/catalog/shift_15n_sq.py#L70-L74), [shift_13c_sq.py](../../src/chemex/experiments/catalog/shift_13c_sq.py#L70-L74)
- **Mechanism**: `SpectrometerAnalysis.calculate_shifts()` computes `np.linalg.eigvals(liouv).imag` on a **real** Cartesian Liouvillian (`ixy` or `ixy_ixysxy` with `carrier = 0.0`). Because the matrix is real, every physical precession frequency $+\omega_k$ ($-1$ coherence) is accompanied by its complex-conjugate ghost $-\omega_k$ ($+1$ coherence). Furthermore, `shift_15n_sqmq` pools all single-quantum (`ix, iy, sx, sy`) and multiple-quantum (`2ixsx, 2ixsy, 2iysx, 2iysy`) operators into a single $12 N_{\text{states}}$ spectrum and picks `shift_sq`, `shift_dq`, and `shift_zq` solely via `_find_nearest(shifts, ref_shift)` against `cs_a * ppm`.
- **Demonstrated Failures** (empirically verified):
  1. **Silent `0.0` ppb output when `CS_A` is omitted**: Unlike CEST experiments (`ConditionsWithValidations`), `Shift15NSqMqConfig` does not require `CS_A`, which defaults to `0.0` in [spins.py](../../src/chemex/parameters/spins.py#L258-L269). When `cs_i_a = cs_s_a = 0.0` (or whenever `cs_s_a = 0.0`), `ref_shift_i == ref_shift_dq == ref_shift_zq`, so all three `_find_nearest` calls select the **identical eigenvalue** and `shift_sq - 0.5 * (shift_dq + shift_zq)` returns **`[0.0]` ppb identically** regardless of `dw_ab`, `kex`, or `pb` (tested at `pb = 0.10, dw_i_ab = 5.0 ppm, dw_s_ab = 0.8 ppm`: output is `[0.]` ppb).
  2. **Catastrophic DQ sign flip on Glycine residues**: Because $\gamma_N < 0$ (`ppm_i < 0`) and $\gamma_H > 0$ (`ppm_s > 0`), `ref_shift_dq = cs_i_a * ppm_i + cs_s_a * ppm_s` crosses zero near $\delta_H \approx 0.10133\,\delta_N$ (e.g., typical Glycine amides around $\delta_N \approx 102\text{ ppm}, \delta_H \approx 10.33\text{ ppm}$). Whenever exchange pushes $\omega_{\text{DQ}}$ across zero, `_find_nearest` jumps onto the conjugate ghost $-\omega_{\text{DQ}}$: for identical exchange parameters (`pb = 0.10, kab = 500, kba = 4500, dw_i_ab = -1.0, dw_s_ab = 0.05`), `shift_15n_sqmq` returns **`+108.48` ppb** at `(120.0, 8.5)` ppm but jumps by 220 ppb to **`-111.10` ppb** at `(102.0, 10.3336)` ppm.
  3. **SQ sign bounce near `0.0` ppm**: In `shift_13c_sq` / `shift_15n_sq`, a methyl $^{13}\text{C}$ near `0.0` ppm (`cs_i_a = 0.05 ppm, dw_i_ab = -2.0 ppm`) returns `+0.0450 ppm` instead of `-0.1058 ppm` because the conjugate ghost of `-0.1058 ppm` (`+0.1058 ppm`) is closer to `+0.05 ppm` (and at `cs_i_a = 0.0`, $\pm\omega_{\text{obs}}$ tie and sign depends on LAPACK eigenvalue ordering).
- **Root Fix**: Form the complex scalar coherence sub-Liouvillians $I_+ = I_x + i I_y$, $I_+ S_+$ (DQ), and $I_+ S_-$ (ZQ) of dimension $N_{\text{states}} \times N_{\text{states}}$ directly. This eliminates conjugate ghost eigenvalues completely, separates SQ/DQ/ZQ subspaces unconditionally (making `CS_A` unnecessary for isotropic shift differences!), and reduces eigendecomposition cost from $(12 N)^3$ to three $N^3$ solves.

#### 1.2 [Confirmed Defect] Inverted Sign in Anti-Phase $^{13}\text{C}$ Relaxation Constraint `r2a_i = {r2_i} - {r1_s}` Across All Non-Model-Free `spin_system="ch"` Experiments
- **Locations**: [spins.py](../../src/chemex/parameters/spins.py#L24-L38), [spins.py](../../src/chemex/parameters/spins.py#L155-L176), [rates.py](../../src/chemex/nmr/rates.py#L113-L141)
- **Mechanism**: Base spin settings define `r2a_i_{state}` with `value=12.0` (`10.0 + 1.5`), yet hardcode `expr=f"{r2_i_{state}} - {r1_s_{state}}"` (and `r2a_s = {r2_s} - {r1_i}`). `_update_expr_for_proton_exchange` overrides this expression for `"nh"` and `"hn"`, **but omits `"ch"` and `"hc"`**. Physically, longitudinal flips of the attached $^1\text{H}$ spin $S$ driven by external $^1\text{H}\text{–}{}^1\text{H}$ dipolar interactions ($d_{SH}^2 J(0) \propto \tau_c$) **add** $+R_{1,S}$ to anti-phase $2I_{xy}S_z$ relaxation ($R_{2a,I} \approx R_{2,I} + R_{1,S}$), as ChemEx's own `RateCH` Redfield implementation confirms: at $600\text{ MHz}, \tau_c = 8\text{ ns}, S^2 = 0.85$, `RateCH` gives `r2_i = 31.764 s^-1`, `r1_s = 9.848 s^-1`, and **`r2a_i = 41.426 s^-1`**, whereas `spins.py` evaluates `r2_i - r1_s = 21.916 s^-1`—an error of nearly $20\text{ s}^{-1}$ in `cest_13c`, `dcest_13c`, `coscest_13c`, `cpmg_13c_ip`, `cpmg_ch3_13c_h2c`, `cpmg_ch3_13c_h2c_0013`, and `cpmg_ch3_mq`. Worse, if $R_{1,S} > R_{2,I}$, `r2a_i` becomes negative, either producing unphysical gain or failing bound checks. (Also note in `_update_expr_for_proton_exchange` line 37: `"nh"` clears `r1a_is.expr = ""`, whereas `"hn"` does not.)

#### 1.3 [Confirmed Defect] Propagator Calculation (`np.linalg.eig` + `np.linalg.solve`) Has Dead `expm` Fast-Path and Silently Drops Secular Exchange Terms or Crashes at Jordan Blocks
- **Locations**: [propagators.py](../../src/chemex/nmr/_pulses/propagators.py#L33-L73), [tensors.py](../../src/chemex/nmr/_engine/tensors.py#L39), [native.py](../../src/chemex/evaluation/native.py#L1780-L1833)
- **Mechanism**:
  1. Line 43 (`if liouv_array.ndim == 2 and delays_array.size == 1 and not dephasing: return expm(...)`) is **dead code for every `Spectrometer` call** because `ISLiouvillianEngine` tensors always have 4D shape `(n_jeff, n_b1, size, size)`. Every single delay and RF pulse runs `np.linalg.eig` + `np.linalg.solve`.
  2. Non-Hermitian Bloch-McConnell Liouvillians are not normal and possess genuine **exceptional points (defective $2\times 2$ Jordan blocks)** along coalescence manifolds (e.g., $p_a = p_b = 0.5, \Delta R_2 = 0, |\Delta\omega| = k_{\text{ex}}$) and boundary manifolds ($p_b = 0, \Delta\omega = 0, R_{2,a} - R_{2,b} = k_{ba}$).
  3. **Demonstrated silent corruption / crash**: At the defective boundary block $L = \begin{pmatrix}-110 & 100 \\ 0 & -110\end{pmatrix}$ ($t = 0.02\text{ s}$), `scipy.linalg.expm(L * t)` yields the exact secular transfer $\begin{pmatrix}0.110803 & \mathbf{0.221606} \\ 0 & 0.110803\end{pmatrix}$. In contrast, `calculate_propagators(L, 0.02)` returns $\begin{pmatrix}0.110803 & \mathbf{0.0} \\ 0 & 0.110803\end{pmatrix}$—**silently annihilating 100% of the off-diagonal exchange transfer without raising any warning**, because when LAPACK returns $\lambda_1 = \lambda_2 = \lambda$ with a rounding-perturbed nonsingular $V_p$, $V_p (e^{\lambda t} I) V_p^{-1} = e^{\lambda t} I$ identically! Conversely, when two columns of $V$ are bit-identical, `np.linalg.solve` raises `LinAlgError: Singular matrix`, which `BoundEvaluator` classifies as `"kernel_exception" -> "IMPLEMENTATION_FAILURE"` ([native.py](../../src/chemex/evaluation/native.py#L1810-L1833)), permanently poisoning the workspace and aborting the fit (`scipy.linalg.expm` supports batched `(..., N, N)` arrays natively and is analytic across Jordan blocks).
  4. **1-element list squeeze bug** ([propagators.py](../../src/chemex/nmr/_pulses/propagators.py#L69-L70)): `if propagators.shape[0] == 1: propagators = propagators[0]` checks `shape[0] == 1` instead of `np.ndim(delays) == 0`. Passing a 1-element list/array of delays when `n_jeff > 1` or `n_b1 > 1` squeezes out the delay axis and exposes `n_jeff` as axis 0, causing `ValueError` in [cpmg_ch3_mq.py](../../src/chemex/experiments/catalog/cpmg_ch3_mq.py#L94) (`zip(..., strict=True)`) or wrong-length outputs in [relaxation_nz.py](../../src/chemex/experiments/catalog/relaxation_nz.py#L94-L103) and [relaxation_hznz.py](../../src/chemex/experiments/catalog/relaxation_hznz.py#L98-L107).

#### 1.4 [Confirmed Defect] Broken Detailed Balance & Non-Stationary Initial State in `4st_hd`, and Broken Thermal Bath When `start_state` Is Set in $^1\text{H}$ IP-AP CEST
- **Locations**: [settings_4st_hd.py](../../src/chemex/models/kinetic/settings_4st_hd.py#L17-L40), [settings_4st_hd.py](../../src/chemex/models/kinetic/settings_4st_hd.py#L92-L138); [cest_1hn_ip_ap.py](../../src/chemex/experiments/catalog/cest_1hn_ip_ap.py#L40-L45), [coscest_1hn_ip_ap.py](../../src/chemex/experiments/catalog/coscest_1hn_ip_ap.py#L45-L49), [cest_ch3_1h_ip_ap.py](../../src/chemex/experiments/catalog/cest_ch3_1h_ip_ap.py#L38-L42)
- **Mechanisms**:
  1. **`4st_hd` microscopic reversibility violation**: `settings_4st_hd` enforces `kcd = kab` and `kdc = kba` while allowing `phi_b` to differ from `phi_a` (via parameter file or fit overrides). Around the 4-state thermodynamic cycle $A \leftrightarrow B \leftrightarrow D \leftrightarrow C \leftrightarrow A$, the forward/reverse product ratio is $\frac{k_{ab} k_{bd} k_{dc} k_{ca}}{k_{ba} k_{db} k_{cd} k_{ac}} \neq 1$ whenever $\phi_b \neq \phi_a$ or fractionation shifts $K_{\text{HX}}$ differently in $A$ vs $B$. Worse, the analytical population expressions (`lines 125-138`) do not lie in the nullspace of the rate matrix $K$: at `phi_a = 1.0, phi_b = 0.5, kex_ab = 200`, the cycle ratio is `1.941 != 1.0`, analytical populations `[0.810, 0.082, 0.090, 0.018]` disagree with steady state `[0.847, 0.094, 0.053, 0.006]`, and $\|K p\|_\infty = 1.47\text{ s}^{-1}$, so magnetization drifts artificially during every delay even without RF irradiation.
  2. **`start_state` zeroes `ie_b` in IP-AP $^1\text{H}$ CEST**: In `cest_1hn_ip_ap`, `coscest_1hn_ip_ap`, and `cest_ch3_1h_ip_ap`, `start_terms` calls `self.get_start_terms("ie")`. In `_eq` bases, `ie_{state}` is the conserved inhomogeneous **thermal-bath source operator** driving longitudinal relaxation $\frac{dI_{z,s}}{dt} = -R_{1,s}(I_{z,s} - I_{e,s}) + \dots$, not initial magnetization (`iz`). Setting `start_state = "a"` sets `ie_b = 0.0`, causing state `b` to relax toward zero during `d1` and `time_t1` (`iz_a = 0.728, iz_b = 0.145` after `d1 = 1.5 s` instead of equilibrium `0.800, 0.200`). Conversely, [coscest_13c.py](../../src/chemex/experiments/catalog/coscest_13c.py#L41-L45) defines `start_terms` (`start_state`) in its schema and cache key, then ignores it on line 145 (`spectrometer.get_equilibrium()`).

#### 1.5 [Confirmed Defect] Unsigned `XI_RATIO` Inverting $^{15}\text{N}$ Heteronuclear NOE Sign, Aliphatic `RateCH` Mapped to Carbonyl `"cn"`, and Missing Aromatic Multiplets
- **Locations**: [magnetization.py](../../src/chemex/nmr/_engine/magnetization.py#L41-L62), [constants.py](../../src/chemex/nmr/constants.py#L26-L36), [constants.py](../../src/chemex/nmr/constants.py#L82-L266), [rates.py](../../src/chemex/nmr/rates.py#L306-L307)
- **Details**:
  1. **Heteronuclear NOE sign**: [constants.py](../../src/chemex/nmr/constants.py#L34-L36) defines `SIGNED_XI_RATIO` (`N15: -0.101329`), yet `build_equilibrium_magnetization` imports unsigned `XI_RATIO` (`+0.101329`). Because `basis.py` and `rates.py` formulate cross-relaxation `sigma_is` in the signed-$\gamma$ basis, any two-spin longitudinal basis (`ixyzsxyz_eq`, `izsz_eq`) computes $I_z^{\text{sat}}/I_e = 1 + (\sigma_{NH}/R_{1N})(+|\gamma_H/\gamma_N|)$ instead of $1 + (\sigma_{NH}/R_{1N})(-|\gamma_H/\gamma_N|)$—yielding an unphysical $^{15}\text{N}\{^1\text{H}\}$ steady-state NOE of **`+1.168`** ($>1$) instead of textbook **`+0.832`** at $\tau_c = 8\text{ ns}$ (and `+5.26` instead of `-3.26` in extreme narrowing).
  2. **Wrong model-free kernel for `cpmg_13co_ap`**: [rates.py](../../src/chemex/nmr/rates.py#L306-L307) maps `"cn": RateCH()` and `"cn_d": RateCHDeuterated()`. Running `cpmg_13co_ap` (`spin_system="cn"`) with `.mf` silently computes carbonyl $^{13}\text{C}'\text{–}{}^{15}\text{N}$ relaxation from aliphatic $^{13}\text{C}\text{–}{}^1\text{H}$ bond lengths ($1.09\text{ \AA}$), $\gamma_H$, and $\Delta\sigma \approx 5.3\text{ ppm}$ instead of carbonyl CSA ($\sim 150\text{ ppm}$) and $\gamma_N$.
  3. **Missing aromatic $^{13}\text{C}$ couplings & unnormalized multiplet weights**: `J_EFF["f"]`, `J_EFF["y"]`, and `J_EFF["w"]` omit all aromatic ring carbons (`cg, cd1, cd2, ce1, ce2, cz, ch2`), and `J_EFF["u"]` omits `"n"`, raising `KeyError` under `label = ["13c"]` in $^{13}\text{C}$/$^{15}\text{N}$ CEST. Also, `get_multiplet` (`lines 262-266`) does not normalize Pascal weights (`sum == 2**n`), scaling unnormalized `simulate` intensities by $2^{n_J}$.

#### 1.6 [Confirmed Defect] IEEE-754 Binary64 ULP Crash in `PopulationSimplex` Decode & Narrow-Box Crash in `FeasibleCoordinates.differential()`
- **Locations**: [feasible_coordinates.py](../../src/chemex/parameters/feasible_coordinates.py#L181-L240), [feasible_coordinates.py](../../src/chemex/parameters/feasible_coordinates.py#L725-L743), [feasible_coordinates.py](../../src/chemex/parameters/feasible_coordinates.py#L1485-L1491), [direct_trf.py](../../src/chemex/optimize/direct_trf.py#L2895-L2913)
- **Mechanism**:
  1. In 3-state / 4-state models with positive lower bounds such as `PB_min = 0.2, PC_min = 0.2`, at the valid solver box boundary `u_pb = 1.0`, IEEE-754 binary64 evaluates `upper_pb = 1.0 - 0.2 = 0.8000000000000000444...` (ULP near `0.8` is $2^{-53}$ vs $2^{-55}$ near `0.2`). On the next coordinate `pc`, `available = 1.0 - upper_pb = 0.1999999999999999556... < lower_pc (0.2000000000000000111...)`. Line 195 (`if lower > upper`) has zero ULP tolerance and raises `ScientificFeasibilityError: Population 'pc' has no feasible simplex interval` (empirically reproduced), which [direct_trf.py](../../src/chemex/optimize/direct_trf.py#L2902-L2913) escalates into `IMPLEMENTATION_FAILURE`, crashing the fit!
  2. In `FeasibleCoordinates.differential()` (`lines 725-743`), when a user narrows `upper - lower < 1.49e-8 * max(1.0, abs(point))`, the fallback backward step `point - step` steps below `lower[column]`, raising `ScientificFeasibilityError` during post-convergence uncertainty linearization.
  3. `_active_population_simplexes` (`lines 1485-1491`) skips simplex compilation altogether if any minor population has an expression constraint (e.g., `[PC] = "[PB]"`), allowing TRF trial steps with `pb + pc > 1` (`pa < 0`).

#### 1.7 [Confirmed Defect] Parameter Parsing, Filtering, Kinetic Edge-Case, Distribution, I/O & Plotting Bugs

### Tier 2 — Statistical & Uncertainty Validity Flaws

#### 2.1 [Statistical Flaw] Deterministic Covariance Gates Ignore Boundary Pinning and Ill-Conditioning, Never Warn on $\chi^2_\nu \gg 1$, and Fail Globally on Single-Residue Rank Deficiency
- **Locations**: [optimize/uncertainty.py](../../src/chemex/optimize/uncertainty.py#L5572-L5626), [deterministic_uncertainty.py](../../src/chemex/optimize/deterministic_uncertainty.py#L425-L479)
- **Issues**:
  1. `_canonical_covariance_claims` (`lines 5596-5625`) painstakingly computes `INTERIOR_POINT`, `BOUNDARY_SEPARATION`, `CONDITIONING_ADEQUACY`, and `AFFINE_FEASIBILITY`, **yet omits all four from `required` when certifying `USABLE_LOCAL_COVARIANCE`**! Consequently, when parameters sit on active bounds (e.g. `pb = 0` or `kex = 0`), ChemEx computes one-sided finite differences and inverts the full unconstrained $(J^T J)^{-1}$—corrupting correlated interior parameter uncertainties via invalid off-diagonal cross-terms—while reporting `SATISFIED`. Arbitrarily ill-conditioned Jacobians ($\kappa > 10^{12}$) are likewise published as usable standard errors up to floating-point collapse.
  2. In global fits (1 connected component), a single unidentifiable local parameter on one poorly sampled residue (`dw = 0` or flat profile) causes `SINGULAR_SENSITIVITY` for the entire component, suppressing deterministic uncertainties for **all** residues and global kinetic parameters.
  3. `ABSOLUTE_OBSERVATION_UNCERTAINTIES` fixes residual dispersion scale $\phi = 1.0$ unconditionally (`deterministic_uncertainty.py:425-479`) without warning or flagging under-estimated uncertainties when $\chi^2_\nu \gg 1$.
  4. **Missing analytical/FD linearizations for 12 kinetic models & `.mf`**: None of the 5 binding models, 5 oligomerization models, `2st_hd`, `4st_hd`, or model-free (`RateNH`, `RateCH`, etc.) register entries in `function_linearization_registry`, leaving derived rate/population/relaxation parameter uncertainties permanently `UNSUPPORTED_CONSTRAINED_DERIVATIVE`.

#### 2.2 [Confirmed Defect / Statistical Flaw] MCMC Uses Unburned Chains for Autocorrelation/ESS, Overdisperses & Boundary-Clips Walkers, Uses Unmarginalized Profile $\chi^2$, and Omits Derived Posteriors
- **Locations**: [native_mcmc.py](../../src/chemex/optimize/native_mcmc.py#L578-L591), [native_mcmc.py](../../src/chemex/optimize/native_mcmc.py#L1017-L1021), [native_mcmc.py](../../src/chemex/optimize/native_mcmc.py#L3833-L3865), [native_mcmc.py](../../src/chemex/optimize/native_mcmc.py#L4976-L5050)
- **Issues**:
  1. **Pre-burn autocorrelation bug**: In `_summarize_mcmc_chain` (`lines 4976-5050`), `_estimate_product_autocorrelation_time(raw_chain)` is computed on the **unburned `raw_chain`** (dominated by initial burn-in transient drift) and then passed unchanged into `_effective_sample_size(retained_chain, autocorrelation_time)` even when `burn` was explicitly configured—systematically distorting ESS, MCSE, and `STATISTICALLY_USABLE` claims.
  2. **Broken walker initialization**: `_initial_walker_positions` (`lines 578-591`) ignores `fit.deterministic_uncertainty` covariance and sets walker spread to `(upper - lower) * 1e-4`. For wide default safety bounds like `kex` in `[0, 1e6] s^-1`, walkers scatter across `±100 s^-1` around a narrow MLE (`<1%` acceptance), while `np.clip` collapses ~50% of walkers onto exact boundary hyperplanes when the MLE is near a bound (breaking `emcee` affine-invariant stretch moves).

#### 2.3 [Confirmed Defect / Statistical Flaw] Bootstrap Freezes Single Reference Planes, `bsn` Injects a ~36.8% MLE Spike into Local Parameters, and `statistics.toml` Misreports DoF
- **Locations**: [native_resampling.py](../../src/chemex/optimize/native_resampling.py#L914-L990), [native_resampling.py](../../src/chemex/optimize/native_resampling.py#L1191-L1195), [resampling.py](../../src/chemex/optimize/resampling.py#L328), [helper.py](../../src/chemex/optimize/helper.py#L54-L103), [statistics.py](../../src/chemex/optimize/statistics.py#L29-L42)

  1. **Zero noise on single reference planes in `bs`**: `_bootstrap_profile_indices` (`lines 914-938`) resamples `reference_pool` and `signal_pool` separately.   2. **~36.8% point-mass artifact in `bsn`**: Nucleus bootstrap (`bsn`) omits each spin system with probability $(1 - 1/K)^K \approx e^{-1} \approx 36.8\%$ per replicate (`lines 959-990`), yet solves a single monolithic TRF over all `source_problem.controlled_ids` starting at `accepted_vector` (`lines 1191-1195`). ### Tier 3 — Major Performance, Scalability & Concurrency Bottlenecks

#### 3.1 [Performance Bottleneck] Dense Uncolored Finite-Difference Jacobians in Global Fits + Severe Per-Evaluation Overhead
- **Locations**: [direct_trf.py](../../src/chemex/optimize/direct_trf.py#L2848-L2971), [direct_trf.py](../../src/chemex/optimize/direct_trf.py#L3197-L3217), [native.py](../../src/chemex/evaluation/native.py#L276), [profile.py](../../src/chemex/containers/profile.py#L87-L95), [optimize/uncertainty.py](../../src/chemex/optimize/uncertainty.py#L3727-L3741)
- **Impact**:
  1. **Missing `jac_sparsity` in global fits**: A 100-residue global fit with 2 global kinetic parameters and 4 local parameters per residue ($P = 402$, $M \approx 6000$) has a block-arrow Jacobian that is ~99% zeros and graph-colorable into **~6** function evaluations per TRF iteration. Because `direct_trf.py:3204` calls `scipy.optimize.least_squares(..., jac="2-point", tr_solver="exact")` without `jac_sparsity`, SciPy performs **402 sequential FD calls** per iteration plus dense $O(M P^2)$ SVDs.
  2. **Per-call serialization, boxing & Pydantic overhead**: Every single FD perturbation hashes the full vector via JSON + SHA-256 twice (`_vector_digest`), boxes all $M$ float64 residuals into Python `float` tuples, appends unbounded `_CompletedRequest` audit objects to `self.requests` (`direct_trf.py:2957`), double-copies arrays via `tobytes()` in `_readonly` (`native.py:276`), instantiates and validates a fresh 6-array Pydantic `Data` object per profile (`profile.py:87-95`), and runs global `eigvalsh` across all residues (`feasible_coordinates.py:712`).
  3. **$O(P^3)$ pure-Python matrix multiplication**: `_gram_matrix` ([optimize/uncertainty.py](../../src/chemex/optimize/uncertainty.py#L3727-L3741)) multiplies $P \times M$ matrices via triple nested Python loops and recursive list-slicing `_pairwise_sum` (~$10^8$ Python ops at $P=400$), and then immediately calls BLAS `factor_array @ factor_array.T` on line 3745 just to check its own result!

#### 3.2 [Performance Bottleneck] Unbatched Python Offset Loops in CEST and Uncached Liouvillian / Composite-Pulse Rebuilds
- **Locations**: [cest_15n.py](../../src/chemex/experiments/catalog/cest_15n.py#L103-L112) (and all 10 other `*cest*.py` modules), [engine.py](../../src/chemex/nmr/_engine/engine.py#L96-L103), [engine.py](../../src/chemex/nmr/_engine/engine.py#L277-L288), [library.py](../../src/chemex/nmr/_pulses/library.py#L86-L157), [kernel.py](../../src/chemex/nmr/_pulses/kernel.py#L98-L107)
- **Impact**:
  - Every CEST module loops in Python `for offset in set(offsets): spectrometer.offset_i = offset; spectrometer.pulse_i(...)`. In our empirical benchmark on a 65-offset $14\times 14$ 2-state $^{15}\text{N}$ CEST profile, a single batched `scipy.linalg.expm` call ran in **`0.467 ms` vs `2.521 ms`** for ChemEx's Python `calculate_propagators` loop (**`5.4x` speedup** on the kernel alone, before even counting `l_free` summation overhead).
  - `ISLiouvillianEngine.l_free` (`engine.py:277-288`) is never cached against `_free_generation`, summing 6 matrices on every delay/pulse call; `_build_base_liouvillian` (`lines 96-103`) sums 10–30 matrices in Python instead of `einsum`; and `PulseLibrary.p9024090_nh_1/2` (`library.py:136-157`) lacks `_built_generation` caching, recomputing 8 full two-spin eigendecompositions per spin-system evaluation.

#### 3.3 [Performance & Concurrency Flaw] Sequential Deterministic Fits, GIL-Bound Resampling Threads, and Ineffective Post-Import BLAS Thread Control
- **Locations**: [execution.py](../../src/chemex/runtime/execution.py#L64-L80), [chemex.py](../../src/chemex/chemex.py#L219), [native_resampling.py](../../src/chemex/optimize/native_resampling.py#L2662-L2663), [direct_trf.py](../../src/chemex/optimize/direct_trf.py#L1660), [grouped_direct_trf.py](../../src/chemex/optimize/grouped_direct_trf.py#L979), [profiled_grid.py](../../src/chemex/optimize/profiled_grid.py#L627)
- **Impact**:
  1. Deterministic fitting (`grouped_direct_trf`, `profiled_grid`, `de_direct_trf`) hardcodes `workers = 1`, running 100 independent residue fits or 400 grid points strictly sequentially regardless of `--workers`.
  2. `native_resampling.py:2663` uses `ThreadPoolExecutor` (contradicting [cli.py](../../src/chemex/cli.py#L47) *"worker processes"*), incurring heavy GIL contention across Python-heavy evaluation/proof code and `deepcopy`-ing every `Profile`/`Spectrometer` per replicate (`native.py:1644`).
  3. `native_thread_environment` sets `OMP_NUM_THREADS="1"`, `OPENBLAS_NUM_THREADS="1"`, etc. in `os.environ` **after** `numpy` and `scipy` have already initialized their C thread pools—a no-op on OpenBLAS/Accelerate/MKL without `threadpoolctl`, risking $N^2$ BLAS thread oversubscription (and `chemex.py:219` mutates `os.environ` permanently for library callers).

## 4. Important Uncertainties & Areas Not Assessed

1. **Full `scientific_acceptance` End-to-End Regression Suite**: Because the workspace `.venv/bin/python` symlink pointed to a removed Python 3.13 installation while `cpython-3.14.10` was active in `uv`, targeted reproductions were executed via `uv run --isolated --locked --no-editable --offline` without modifying `.venv`, rather than running the full multi-minute `pytest -m scientific_acceptance` suite across all shipped examples.
